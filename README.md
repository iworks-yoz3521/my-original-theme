# My Portfolio

WordPressを使用して制作した
オリジナルのポートフォリオサイトです。

## 概要

Web制作の学習記録や制作実績を紹介するために、
WordPressのオリジナルテーマを制作しました。

## 使用技術

- HTML5
- CSS3
- PHP
- WordPress
- Contact Form 7
- Local
- Visual Studio Code

## 主な機能

- オリジナルテーマ
- トップページ
- 自己紹介ページ
- 投稿一覧・投稿詳細ページ
- ナビゲーションメニュー
- アイキャッチ画像
- お問い合わせフォーム
- サイトアイコン

## デザイン

ネイビーとライトブルーを基調とした、
シンプルで統一感のあるデザインにしました。

## ファイル構成

- front-page.php：トップページ
- header.php：ヘッダー
- footer.php：フッター
- functions.php：テーマの機能設定
- index.php：投稿一覧ページ
- page.php：固定ページ
- single.php：投稿詳細ページ
- style.css：スタイルシート
- images/：画像ファイル

## 学習したこと

- WordPressのテーマ制作
- PHPによる動的なページ表示
- テンプレートファイルの役割
- CSSによるデザインの実装
- お問い合わせフォームの設定
- ローカル環境での動作確認

## 動作環境

Localを使用したWordPressのローカル開発環境で
制作・動作確認を行いました。

## 今後の目標

Web制作の知識と技術をさらに深め、
使いやすく見やすいWebサイトを
